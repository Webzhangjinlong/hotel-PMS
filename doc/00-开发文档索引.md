## 4. 开发流程指南

### 开发前准备
1. 从 [05-功能开发进度.md](05-功能开发进度.md) 确认要开发的功能项
2. 从 [02-功能设计.md](02-功能设计.md) 了解功能需求和验收标准
3. 从 [03-技术设计.md](03-技术设计.md) 确认技术规范
4. 从 [06-代码开发规范.md](06-代码开发规范.md) 查看代码规范
5. 从 [08-接口文档.md](08-接口文档.md) 查看API接口定义

### 开发中执行
6. 遵循分层架构：api → service → dao → common
7. 遵循命名规范和注释规范
8. 遵循编码规范（BigDecimal、TIMESTAMP、逻辑删除）
9. 编写测试代码

### 开发后收尾
10. 更新 [05-功能开发进度.md](05-功能开发进度.md)
11. 如有数据库变更，更新 [04-SQL脚本记录.md](04-SQL脚本记录.md)
12. 如有接口变更，更新 [08-接口文档.md](08-接口文档.md)

## 6. 附录

### 命名规范速查
| 类型 | 规范 | 示例 |
|------|------|------|
| 包名 | com.hotel.pms.{模块} | com.hotel.pms.auth |
| 类名 | 大驼峰 | SysAccount |
| 方法名 | 小驼峰 | getById |
| 接口路径 | /api/v1/{模块}/* | /api/v1/auth/* |

### 编码规范速查
| 场景 | 规范 |
|------|------|
| 金额 | BigDecimal，禁止浮点 |
| 时间 | TIMESTAMP，默认 CURRENT_TIMESTAMP |
| 逻辑删除 | deleted BOOLEAN DEFAULT FALSE |
| 敏感数据 | AES-GCM 加密 |
| 文件编码 | UTF-8 无 BOM |
| 字符集 | UTF-8 |
| 时区 | Asia/Shanghai |
