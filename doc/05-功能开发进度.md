## 操作日志功能（2026-08-20）

### 功能概述
实现系统操作日志的自动记录和查询功能，通过AOP切面自动拦截关键业务操作并记录到数据库。

### 后端实现
| 文件 | 说明 |
|------|------|
| `OperationLog.java` | 自定义注解，用于标记需要记录的方法 |
| `OperationLogAspect.java` | AOP切面，自动拦截并记录操作日志 |
| `OperationLogEntity.java` | 操作日志实体类 |
| `OperationLogMapper.java` | MyBatis Mapper接口 |
| `OperationLogService.java` | 操作日志查询服务 |
| `OperationLogController.java` | REST API控制器 |
| `OperationLogQueryDTO.java` | 查询参数DTO |

### 前端实现
| 文件 | 说明 |
|------|------|
| `operationLog.js` | API接口定义 |
| `OperationLogs.vue` | 操作日志查询页面 |

### 已接入模块（共44个注解）
| 模块 | Controller | 注解数 | 记录的操作 |
|------|------------|--------|-----------|
| 登录登出 | AuthController | 2 | 登录、登出 |
| 预订管理 | ReservationController | 5 | 创建/修改/取消/确认预订 |
| 预订管理 | TeamReservationController | 8 | 团队预订、入住、退房、分配房间 |
| 入住管理 | StayController | 2 | 散客入住、退房 |
| 房态管理 | RoomController | 4 | 创建/修改/删除房间、修改房态 |
| 价格管理 | RoomPriceController | 3 | 修改房价、批量调价、初始化房价 |
| 账务管理 | FolioController | 3 | 收款、退款、冲账 |
| 预付款管理 | PrepaymentController | 3 | 预订预付、预付转入住、预付退款 |
| 挂账管理 | CreditCompanyController | 3 | 创建/修改挂账公司、挂账结算 |
| 交班管理 | ShiftController | 3 | 提交/接收/确认交班 |
| 夜审管理 | NightAuditController | 3 | 执行夜审、重试步骤、重置状态 |
| 用户管理 | UserController | 5 | 创建/修改/删除用户、重置密码、分配角色 |

### 功能特性
- **自动记录**：通过AOP注解自动拦截，无需手动调用
- **操作模块**：12个业务模块全覆盖
- **操作类型**：登录、登出、创建、修改、删除、确认、取消、入住、退房、收款、退款、冲账、结算等
- **查询筛选**：支持按模块、操作类型、操作人、日期范围筛选
- **详情查看**：支持查看操作日志详细信息
