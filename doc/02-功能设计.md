## 1. 功能分级定义

| 优先级 | 含义 | 交付要求 |
|---|---|---|
| P0 | 前台日常运营闭环，无此功能不可上线 | 必须完成 |
| P1 | 重要但不影响上线 | 尽快补充 |
| P2 | 锦上添花 | 后续迭代 |

## 5. 页面形态

- Web 管理端优先，第一屏为**前台工作台**：房态图 + 今日抵店/离店 + 快速入住退房。
- 房态图支持按楼层/分区筛选，颜色区分：空闲绿、在住红、脏房灰、维修橙、OOO 紫、预留蓝。
- 本轮不做 PMS 小程序。

## 6. 验收标准

| 场景 | 标准 |
|---|---|
| 房态看板 | 150 间房 3 秒内加载完成 |
| 前台操作 | 单次操作反馈 1 秒内 |
| 防超卖 | 批量分房/批量房态变更 10 间以上不超卖 |
| 账务闭环 | 散客入住 → 挂杂费 → 夜审过账 → 结账退房全链路金额一致 |
| 夜审 | 150 间房全量过账 60 秒内完成，日报与账务流水一致 |
| 交接班 | 当班现金流水与交班核对一致 |
| 公安 | 上传失败自动重试，人工补传可用 |
| 集成 | 模拟通道可运行，PMS 侧事件契约自测通过，真实 OTA 联调留待后续 |

## 7. 功能模块详细描述

### 7.1 登录与权限模块
**功能描述**：提供用户登录、权限验证、角色管理功能

**主要功能**：
- 用户名密码登录
- JWT Token认证
- 验证码校验
- 角色权限管理
- 多酒店登录支持（酒店标识码）

**业务规则**：
- 密码错误5次锁定30分钟
- Token有效期24小时
- 支持多角色权限控制

### 7.2 主数据模块
**功能描述**：管理酒店基础数据，包括楼层、房型、房间

**主要功能**：
- 楼层管理（CRUD）
- 房型管理（CRUD）
- 房间管理（CRUD、房态统计）
- 酒店管理（CRUD、酒店标识码）

**业务规则**：
- 房间号在酒店内唯一
- 房型编码在酒店内唯一
- 支持批量导入导出

### 7.3 房价管理模块
**功能描述**：管理房价策略，支持多种定价方式

**主要功能**：
- 房价码管理（支持多房型打包定价）
- 房价日历（按日期设置房价）
- 房价规则（周末加价、节假日加价等）
- 批量调价功能

**业务规则**：
- 价格查询优先级：房价码 > 日历价 > 基础价
- 支持折扣类型：无折扣、百分比折扣、固定金额折扣
- 价格变更需记录操作日志

### 7.4 预订管理模块
**功能描述**：处理散客和团队预订

**主要功能**：
- 散客预订（创建、修改、取消、确认）
- 团队预订（创建、分配房间、确认、取消）
- 预订状态管理（待确认、已确认、已入住、已取消、未到店）
- 今日抵店列表

**业务规则**：
- 预订创建即占用库存
- 同一房间并发预订需行锁校验
- 预订取消需释放库存

### 7.5 入住管理模块
**功能描述**：处理客人入住和退房

**主要功能**：
- 散客入住（支持房价码选择）
- 预订入住
- 团队入住
- 入住类型筛选（全部/散客/团队/预订）
- 续住功能
- 退房功能

**业务规则**：
- 入住需登记客人信息
- 入住需公安上传
- 退房需结清账务

### 7.6 账务管理模块
**功能描述**：管理客人账务和支付

**主要功能**：
- 账务单管理
- 收款记录
- 挂账公司管理
- 支持多种支付方式（现金、微信、支付宝、POS）

**业务规则**：
- 金额使用BigDecimal，禁止浮点
- 流水只增不改，错误用冲账纠正
- 支持预付款和挂账

### 7.7 夜审模块
**功能描述**：每日结业处理

**主要功能**：
- 自动过房费
- 处理超时离店
- 团队账务汇总
- 公安上传检查
- 计算统计指标（入住率、ADR、RevPAR）
- 生成营业日报
- 锁定数据

**业务规则**：
- 默认每日04:00执行
- 150间房全量过账60秒内完成
- 失败步骤支持重试

### 7.8 交接班模块
**功能描述**：处理前台交接班

**主要功能**：
- 开班会
- 交班收银核对
- 交班记录
- 现金清点

**业务规则**：
- 交接班时冻结当班收银流水
- 未结账务可跨班继续处理

## 8. 用户故事

### 8.1 前台接待用户故事
**作为**前台接待，**我希望**能够快速为客人办理入住，**以便**提高服务效率。

**验收标准**：
- 1分钟内完成散客入住
- 支持选择房价码
- 自动公安上传
- 收取押金并打印收据

### 8.2 店长用户故事
**作为**店长，**我希望**能够查看营业日报，**以便**了解酒店经营状况。

**验收标准**：
- 日报包含入住率、ADR、RevPAR等指标
- 支持历史对比
- 支持导出Excel

### 8.3 财务人员用户故事
**作为**财务人员，**希望能够**管理客人账务，**以便**准确核算收入。

**验收标准**：
- 支持多种支付方式
- 支持退款和冲账
- 流水记录完整

### 8.4 管理员用户故事
**作为**管理员，**希望能够**管理系统配置，**以便**维护系统正常运行。

**验收标准**：
- 支持酒店信息管理
- 支持用户权限管理
- 支持系统参数配置

## 9. 交互流程

### 9.1 预订入住交互流程
`
1. 前台选择"散客入住"
2. 输入客人信息（姓名、电话、证件号）
3. 选择房间（房型、房间号）
4. 选择房价码（可选）
5. 确认入住信息
6. 收取押金
7. 打印入住单
8. 系统自动公安上传
`

### 9.2 退房结账交互流程
`
1. 前台选择"退房"
2. 输入房间号或入住单号
3. 系统显示账务明细
4. 确认消费项目
5. 选择支付方式
6. 完成结账
7. 打印账单
8. 释放房间为脏房
`

### 9.3 夜审执行交互流程
`
1. 系统自动触发或手动执行
2. 显示夜审进度
3. 逐步执行夜审步骤
4. 显示执行结果
5. 生成营业日报
6. 锁定当日数据
`
